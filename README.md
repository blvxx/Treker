# Вдох — трекер восстановления после сигарет

A standalone Russian-language web app for tracking milestones during recovery after quitting smoking. Built as a single-page HTML/CSS/JavaScript project.

## Features

- Progress and time-based milestones
- Personal recovery dashboard and motivational information
- Responsive interface for desktop and mobile
- Custom dark visual theme and lightweight, dependency-free implementation

## Run locally

No build tools or dependencies are required. Open `index.html` in a modern browser.

## Tech

HTML · CSS · JavaScript · Responsive UI

## Project note

This is an independent personal prototype, not a medical tool. Its informational content should not replace professional medical advice.
